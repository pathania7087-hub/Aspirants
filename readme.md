**3. Objectives:**

* Provide information about competitive and government examinations in one place.
* Notify students about important updates such as registration, exam dates, admit cards, answer keys, results, and deadlines.
* Reduce the need to regularly check multiple official examination websites.
* Provide a personalized dashboard and exam calendar for important dates.

**4. Project Description:**
Exam Notifier is a web-based platform that helps students keep track of competitive and government examinations. Users can choose the examinations they are preparing for and receive important updates through **WhatsApp notifications**. The platform will display exam details, upcoming deadlines, exam dates, and recent updates in a single dashboard. An admin panel will allow verified examination updates to be added and automatically notify the relevant students. The initial version will use manually verified updates, with future scope for API integration, web scraping, and AI-based notification summaries.

**5. Technologies Used:**

* **Frontend:** HTML, CSS, Tailwind CSS
* **Backend:** Java, Spring Boot
* **Database:** MySQL
* **Authentication:** JWT
* **Notifications:** WhatsApp API
